# Pomodoro Timer

Консольный таймер помодоро на Python: чередует время работы и отдыха,
показывает обратный отсчёт и полосу прогресса.

## Возможности

- Готовые шаблоны (работа / отдых / число кругов):
  - Мини: 10 / 3 мин, 4 круга
  - Короткий: 15 / 5 мин, 4 круга
  - Классический: 25 / 5 мин, 4 круга
  - Удлиненный: 50 / 10 мин, 2 круга
  - Глубокая работа: 90 / 20 мин, 1 круг
- Свой шаблон: ввод минут работы, минут отдыха и числа кругов (вариант `0`)
- Обратный отсчёт и полоса прогресса на одной обновляемой строке
- Цветной вывод: работа, отдых, окончание
- Проверка ввода: буквы и числа не больше нуля
- Остановка по Ctrl+C

## Запуск

Нужен Python 3, сторонние библиотеки не требуются.

```
python3 timer.py
```

Введите название шаблона или `0` для своего.

## Для проверки

В начале файла есть переменная `seconds_in_minute`. Значение 60 это обычные
минуты, значение 1 ускоряет таймер для тестов (минута проходит за секунду).

## Планы

Окно с картинкой, выбор музыки и фоновых звуков, свои шаблоны с сохранением.
